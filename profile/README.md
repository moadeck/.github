# 모건 · Moadeck

### 세 번 할 일이면 두 번째에 도구를 만든다.

**작은 도구로, 반복 작업에 쓰는 힘을 줄입니다.**

Moadeck은 브라우저 로컬 유틸리티 프로젝트입니다. 거창한 플랫폼보다, 지금 눈앞의 번거로움을 덜어주는 명확한 도구를 지향합니다.

## 덜 반복하고, 더 집중하기

- **데이터 정리의 마찰 줄이기** · 데이터 정제와 배치 자동화 경험을 바탕으로, 반복되는 입력·변환·확인 과정을 단순하게 바라봅니다.
- **작게 만들어 바로 확인하기** · Java·Spring·웹 개발과 1인 챗봇 개발 경험에서 배운 실용적인 제작 방식을 이어갑니다.
- **결과를 읽기 쉽게** · 커머스와 데이터 시각화 경험을 바탕으로, 기능의 수보다 이해하기 쉬운 흐름과 결과에 집중합니다.

## 만드는 기준

1. 한 도구가 해결하는 일을 분명하게.
2. 입력과 결과를 사용자가 확인할 수 있게.
3. 불필요한 데이터 이동을 줄이는 로컬 중심으로.

## 프로젝트 안내

브라우저에서 사용하는 로컬 유틸리티 프로젝트입니다. 제공 도구와 사용 조건은 웹사이트의 현재 안내를 기준으로 확인해 주세요. 민감한 데이터를 다루기 전에는 해당 도구의 처리 방식을 확인하는 것을 권합니다.
